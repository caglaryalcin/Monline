Geist and Geist Mono

Variable WOFF2 subsets, served locally without requests to a font CDN.
These are the same font assets used by the reference Coffer application.
Latin and Latin Extended subsets include German and Turkish characters.
Additional Cyrillic, Vietnamese and symbol subsets retain existing language coverage.

Typeface source: https://github.com/vercel/geist-font
